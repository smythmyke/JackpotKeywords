Design notes:
- Clusters are sorted by best score descending — jackpot clusters float to top
- Jackpot icon + gold left border on clusters containing 75+ keywords
- Click to expand/collapse — shows the flat keyword table inside
- Cluster summary row at bottom shows combined volume + actionable hint
- Cluster name is AI-generated (Gemini names the group based on semantic similarity)
- Each cluster gets the dominant intent badge
- "Select all" checkbox in cluster selects all keywords for export
- Cluster count shown in category tabs alongside keyword count
- Clusters work within existing category tab system — not a replacement
- Toggle between Keywords (flat list) and Clusters (grouped) view

Key interaction:
- Intent filter buttons toggle (like the existing filter bar selects)
- In Keywords view: filters rows in the table
- In Clusters view: hides entire clusters whose dominant intent doesn't match
- Selecting a cluster's checkbox selects all its keywords for batch export
- Export respects both views — "Export selected clusters" exports all keywords in selected clusters
