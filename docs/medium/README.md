## Per-piece publishing checklist

When publishing each piece on Medium:

- [ ] Paste markdown into Medium editor (Medium parses headings, lists, tables, links cleanly)
- [ ] Set canonical URL: **Settings (•••) → More settings → Advanced → Canonical URL**, paste the URL from the table above
- [ ] Add a hero image (Medium auto-features the first image — see "Images" below)
- [ ] Set 5 tags (see suggested tags per piece below)
- [ ] Add author bio (see "Author bio" below)
- [ ] Schedule for **Tuesday or Wednesday morning, 7–9am ET** (Medium's highest engagement window)
- [ ] After publishing, submit to a publication (see "Publication targets")

## Why canonical URL matters

Medium's domain authority is high, so without a canonical tag Google may index the Medium version *instead of* your blog post. Setting canonical to the JK URL tells Google "the original lives at JK; index that one." You still get Medium's distribution; you don't lose your SEO equity.

## Images

Medium auto-features the first image as the hero card. Options:

- **Easiest:** screenshot of the JK results page (showing Jackpot Score, intent labels, trend column). Use the same `/blog/jk-results-scores-trends.png` referenced in the source post — upload directly to Medium, don't hotlink.
- **Higher-effort:** Canva quick-design hero matching the article's pull-quote.
- **Skip the in-body `IMAGE_PLACEHOLDER` references from the source posts** — those were for the JK blog. Medium pieces don't need them; the body reads fine without.

## Hooks tested in each piece

| # | Hook style | First sentence pattern |
|---|------------|------------------------|
| 01 | Personal money story | "$1,679/year SEMrush bill that made me wince" |
| 02 | Reaction-to-product | "First time I opened Keyword Planner, 'this is it?'" |
| 03 | Industry-pattern observation | "Free tools that show you the most are estimating most of it" |

All three open with concrete, specific statements rather than abstract intros — Medium's algorithm rewards engagement in the first 30 seconds, and personal/specific hooks outperform generic ones.
