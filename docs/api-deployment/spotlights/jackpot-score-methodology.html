API METHODOLOGY

How the Jackpot Score is calculated

Every keyword the API returns carries a Jackpot Score (0–100) plus real market data. It isn't a guess or a single raw metric resold — it's a composite signal built from four independent data sources, so you can rank opportunities by how winnable they actually are.

1
AI seed generation. From your product description and/or URL, the pipeline extracts grounded product context and generates seed keywords spanning buyer intents (direct, use-case, competitor) — not generic synonyms.
2
Multi-platform autocomplete expansion. Seeds are expanded against real search-autocomplete suggestions, capturing the long-tail phrasing people actually type — including questions and modifiers.
3
Google Keyword Planner enrichment. Every candidate is enriched with real monthly search volume, low/high CPC, and competition level — the same source advertisers price against.
4
Google Trends overlay. Each keyword gets a trend direction (rising / stable / declining) so you can favor momentum over saturation.

The Jackpot Score

A composite of demand (volume), commercial value (CPC), the competition gap, trend momentum, and relevance to your product. Higher = a better opportunity to win. Sort descending and the strongest plays surface first — especially low-competition, high-intent, rising terms.
